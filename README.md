# chat_system-basic

This web-based chat application was developed using the Boost libraries in C++ and the frontend was created with JavaScript, CSS and HTML. The BOOST_ASIO_DISABLE_LIB and BOOST_ERROR_CODE_HEADER_ONLY macros were defined to address linker and compiler issues. The project has utilised AI assistance to improve its efficiency and to collect information on non-standard libraries, particularly the Boost library.
