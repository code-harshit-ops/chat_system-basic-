# chat_system-basic

This web-based chat application was developed using the Boost libraries in C++ and the frontend was created with JavaScript, CSS and HTML. The BOOST_ASIO_DISABLE_LIB and BOOST_ERROR_CODE_HEADER_ONLY macros were defined to address linker and compiler issues. The project also incorporates AI to enhance its effectiveness and gather information on the Non standard libraries used, specifically the Boost library.
